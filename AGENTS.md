# Project guidance

- This repository is the independent implementation of the proposed method.
- Treat the base-paper repository as read-only reference material.
- Do not copy the monolithic baseline runner into this repository.
- Keep physical models, the environment, agents, and experiments separate.
- Add tests for every scientific formula and state transition.
- Make randomness explicit through seeded random-number generators.
- Keep units visible in names or docstrings and document all assumptions.
- Do not label the paper's method as "Proposed Method" here; call it the
  paper best-response baseline.
- Do not add a license, publish, push, or create a remote without the user's
  explicit approval.
